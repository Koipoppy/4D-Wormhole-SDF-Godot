# 同空间虫洞：已打回方案清单（禁止重复）

这份文档记录**已经被明确打回**的实现方案，以及为什么它们在几何上不成立。
以后改同空间虫洞，先对照此表；不要再把其中任何一个方案换个视觉重做一遍。

---

## 1. 平面圆盘 / 圆环传送门

**做法**：两个竖立圆盘，跨过盘面时把位置/朝向按一个刚体旋转映射到另一盘。
**打回原因**：
- 口有固定朝向（一个平面），只能从盘的正面进入，不是"空间中的任意方向"。
- 本质是传送门/屏幕映射，不是通道。

## 2. 球形薄壳传输（thin-shell transfer）

**做法**：两个球面，跨过球面时位置平移 `H→b+(H-a)`，方向沿球面法向反射。
**打回原因**：
- 没有真实的通道体积；玩家跨过球面瞬间换了位置——这就是传送。
- 视觉上即使做出天空/玻璃，也是把结果映射过去，不是几何本身。
- 最近一版 v39 就是这个方案，虽然画面接近参考图，但机制仍被打回。

## 3. M2 三维超曲面通道（surface patch）

**做法**：把喉口建成一个 3D 超曲面 `|p-C(ψ)|=R(ψ)`，与主悬链面取 min，玩家在
这张**曲面**上飞行。
**打回原因**：
- 建模的是喉口的**边界曲面**，不是喉口的**三维体积**；玩家是在壁上走/飞，
  视觉变成一条带状/峡谷，不是参考图里的球形气泡口。
- 虽然数学上是 4D 嵌入，但几何对象选错了（surface vs volume）。

## 4. 三维实体隧道 / 管壁

**做法**：在主 3D 空间里放一根 3D 管，玩家沿管内部飞。
**打回原因**：
- 纯三维结构，第四维没有参与连接；等同于在 3D 世界里挖了一条隧道。
- 不满足"虫洞必须是 4D 结构"。

## 5. 三维体积手柄 / 4D 体积场景

**做法**：平地板 + 两个球形空腔 + 一条从第四维绕过去的三维喉口体积。
**打回原因**：
- 这不是 0.0.2 的方法；0.0.2 的舞台是超悬链面 `rho=R*cosh(w/R)` 本身，
  不是另造的体积场景。
- 虽然位置连续，但几何对象（体积空腔）与 0.0.2 的 Morris–Thorne 喉口不一致。

## 6. 只做视觉（假窗口 / 贴图 / 只加玻璃、绿球、标识）

**做法**：球口里画天空贴图，或只按参考图摆玻璃环、绿球、标识。
**打回原因**：
- 几何不正确时，视觉对不上是必然的；不允许用视觉技巧掩盖错误几何。
- 视觉只是验收标准，不是实现手段。

## 7. 双超悬链面 min 并集（C⁰ 双泡外包络，v44）

**做法**：两份 0.0.2 超悬链面 F1/F2，世界 = `min(F1,F2)=0`；玩家/光线在并集上做约束投影。
**打回原因**：
- `min(F1,F2)=0` 是"两个 4D 实体并集"的**边界**，不是两张曲面的并集；世界是外包络，
  不是"两份完整超悬链面"。
- 接缝处两个切平面不同：法向、外蕴曲率、切空间都跳变；表面只是 C⁰，不是 C¹/C∞。
  实测 w=6 接缝两侧法向夹角约 13.5°，相切点约 74°。
- 光滑测地线方程在接缝处没有定义；投影积分器跨接缝只会得到"位置连续的分段测地线"，
  有折角/折射，不是光滑测地线。
- B/C 共享是并集重叠 + 同一套 floor/sky 渲染的拓扑/场景解释，不是光滑度规识别；
  C 侧天空是背景约定，B 侧地板是距离代理，不是几何本身。
- `catenoid_test` 只检查位置/w 连续，没有检查法向、速度、测地线残差；测试通过不能
  证明几何正确。
- 该构造不是 Einstein 方程的光滑解；接缝等效于零厚度薄壳，若要物理正确需要显式
  Israel 薄壳条件或光滑多喉口度规。

## 8. 双超悬链面 B 侧外包络 / 光滑桥（v44/v45）

**做法**：两份平行超悬链面，世界 = `min(F1,F2)` 或 `smin(F1,F2)`；B 侧靠外包络/光滑桥共享。
**打回原因**：
- B 侧不是"一个房间 + 两个独立球口"，而是两个超悬链面实体的外包络；两份在
  `|w| > R*acosh(d/(2R))` 处重叠，外包络是一座桥/脊。
- 相机在两口正前方时必然落在桥上：两中心之间的点到中心的距离 ≥ d/2，投影到更深的 w；
  参考图的"平地板 + 两个分离球泡"构图在 0.0.2 双超悬链面 B 侧不可能实现。
- 光滑 `smin` 只修掉了 C⁰ 法向跳变，没有改变"外包络/桥"这个全局形状；视觉仍然是被桥
  挡住的合并双泡（见 `build/v45_test.png` / `build/v45_close.png`）。
- 这不是"两个独立空间通过一个虫洞连接"的几何；它是同一 B/C 对上的两个喉口 + 外包络桥。

# 正确方向（下一步）：平 B 房间 + 两个真实 4D 颈部 + 共享 C 超悬链面

- B 房间是平的 3D 空间（地板 z=0），两个口是地板上的两个**独立开口**；
- 每个口接一条真实的 3D 颈部：中心线从房间进入 w，收缩到 0.0.2 喉口半径 R，再打开到 C 侧；
- 两条颈部的 C 侧连接到**同一张 0.0.2 C 超悬链面**；C 天空共享；
- 玩家/光线从口进入颈部，沿颈部连续到 C；再从另一条颈部回到 B；没有位置映射/传送；
- 颈部与房间/C 侧的接缝用有限厚度过渡（或显式 Israel 薄壳）处理；
- 验收要检查法向、速度、测地线残差，而不只是 w 连续。

这样 B 房间保持平、两口保持分离，C 侧仍是 0.0.2 的超悬链面；它既不是 v39 的球面映射，
也不是 v44/v45 的 B 侧外包络桥。

# 中间版本：光滑双喉口超悬链面（v45）

保留每张超悬链面的 Ellis 等距嵌入，但**不要用 `min` 硬并集**。用 C∞ 光滑最小值：

```
F(p) = smin(F1(p), F2(p); κ)
smin(a,b;κ) = min(a,b) - κ * log(1 + exp(-|a-b|/κ))
```

世界 = `F=0` 是一张 **C∞ 三维超曲面**：

- 喉口附近权重饱和，几何退化为精确的 0.0.2 Ellis 超悬链面；
- 两份重叠区用宽度 κ 的光滑颈连接，法向/外蕴曲率连续；
- 测地线方程处处有定义，投影积分器是光滑曲面上的正确积分；
- B/C 通过光滑颈共享；floor 用同一权重混合，C 侧仍然是天空。

κ 要远小于 R 和两喉口间距，默认 `0.35 m`。

**验收/自检**：
- 两个喉口在 w=0，`F1/F2≈0`，且 `F(喉口)≈0`；
- 光滑颈两侧法向夹角小且连续（不再出现 13.5°/74° 的跳变）；
- 跨接缝的测地线速度/法向连续，投影后 `F(p)≈0`；
- B 侧有地板，C 侧无地板；世界线 A→C→B 连续，无位置映射；
- 注意：光滑混合是合法的 3D Riemannian 嵌入，但不是 Einstein 方程的简单解；
  如果要求 GR 解，需要多喉口度规或显式 thin-shell 条件。
