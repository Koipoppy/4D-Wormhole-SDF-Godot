## 1. 平面圆盘 / 圆环传送门

**做法**：两个竖立圆盘，跨过盘面时把位置/朝向按一个刚体旋转映射到另一盘。
**打回原因**：
- 口有固定朝向（一个平面），只能从盘的正面进入，不是"空间中的任意方向"。
- 本质是传送门/屏幕映射，不是通道。

## 2. 球形薄壳传输（thin-shell transfer）

**做法**：两个球面，跨过球面时位置平移 `H→b+(H-a)`，方向沿球面法向反射。
**打回原因**：
- 没有真实的通道体积；玩家跨过球面瞬间换了位置——这就是传送。
- 视觉上即使做出天空/玻璃，也是把结果映射过去，不是几何本身。
- 最近一版 v39 就是这个方案，虽然画面接近参考图，但机制仍被打回。

## 3. M2 三维超曲面通道（surface patch）

**做法**：把喉口建成一个 3D 超曲面 `|p-C(ψ)|=R(ψ)`，与主悬链面取 min，玩家在
这张**曲面**上飞行。
**打回原因**：
- 建模的是喉口的**边界曲面**，不是喉口的**三维体积**；玩家是在壁上走/飞，
  视觉变成一条带状/峡谷，不是参考图里的球形气泡口。
- 虽然数学上是 4D 嵌入，但几何对象选错了（surface vs volume）。

## 4. 三维实体隧道 / 管壁

**做法**：在主 3D 空间里放一根 3D 管，玩家沿管内部飞。
**打回原因**：
- 纯三维结构，第四维没有参与连接；等同于在 3D 世界里挖了一条隧道。
- 不满足"虫洞必须是 4D 结构"。

## 5. 三维体积手柄 / 4D 体积场景（v40/v46，打回）

**做法**：平地板 + 两个球形空腔 + 一条从第四维绕过去的三维喉口体积。
**打回原因**：
- 用户明确不要“真的造一个手柄一样的空间”；0.0.2 的舞台是**一张超悬链面**
  `rho=R*cosh(w/R)` 本身，不是另造的体积场景。
- 虽然位置连续，但几何对象（体积空腔/喉管）与 0.0.2 的 Morris–Thorne 喉口不一致。
- v40/v46 的 A→B 连续性只能证明“体积管是连通的”，不能证明它符合 0.0.2 的几何。

## 6. 只做视觉（假窗口 / 贴图 / 只加玻璃、绿球、标识）

**做法**：球口里画天空贴图，或只按参考图摆玻璃环、绿球、标识。
**打回原因**：
- 几何不正确时，视觉对不上是必然的；不允许用视觉技巧掩盖错误几何。
- 视觉只是验收标准，不是实现手段。

## 7. 双超悬链面 min 并集（C⁰ 双泡外包络，v44）

**做法**：两份 0.0.2 超悬链面 F1/F2，世界 = `min(F1,F2)=0`；玩家/光线在并集上做约束投影。
**打回原因**：
- `min(F1,F2)=0` 是"两个 4D 实体并集"的**边界**，不是两张曲面的并集；世界是外包络，
  不是"两份完整超悬链面"。
- 接缝处两个切平面不同：法向、外蕴曲率、切空间都跳变；表面只是 C⁰，不是 C¹/C∞。
  实测 w=6 接缝两侧法向夹角约 13.5°，相切点约 74°。
- 光滑测地线方程在接缝处没有定义；投影积分器跨接缝只会得到"位置连续的分段测地线"，
  有折角/折射，不是光滑测地线。
- B/C 共享是并集重叠 + 同一套 floor/sky 渲染的拓扑/场景解释，不是光滑度规识别；
  C 侧天空是背景约定，B 侧地板是距离代理，不是几何本身。
- `catenoid_test` 只检查位置/w 连续，没有检查法向、速度、测地线残差；测试通过不能
  证明几何正确。
- 该构造不是 Einstein 方程的光滑解；接缝等效于零厚度薄壳，若要物理正确需要显式
  Israel 薄壳条件或光滑多喉口度规。

## 8. 双超悬链面 B 侧外包络 / 光滑桥（v44/v45）

**做法**：两份平行超悬链面，世界 = `min(F1,F2)` 或 `smin(F1,F2)`；B 侧靠外包络/光滑桥共享。
**打回原因**：
- B 侧不是"一个房间 + 两个独立球口"，而是两个超悬链面实体的外包络；两份在
  `|w| > R*acosh(d/(2R))` 处重叠，外包络是一座桥/脊。
- 相机在两口正前方时必然落在桥上：两中心之间的点到中心的距离 ≥ d/2，投影到更深的 w；
  参考图的"平地板 + 两个分离球泡"构图在 0.0.2 双超悬链面 B 侧不可能实现。
- 光滑 `smin` 只修掉了 C⁰ 法向跳变，没有改变"外包络/桥"这个全局形状；视觉仍然是被桥
  挡住的合并双泡（见 `build/v45_test.png` / `build/v45_close.png`）。
- 这不是"两个独立空间通过一个虫洞连接"的几何；它是同一 B/C 对上的两个喉口 + 外包络桥。

## 9. 两份 B↔C 超悬链面冒充 A↔B 同空间虫洞（v44/v45）

**做法**：两份 0.0.2 超悬链面 F1/F2，世界 = `min(F1,F2)` 或 `smin(F1,F2)`；
两个“口”在 `w=0`。
**打回原因**：
- 每张超悬链面本身是 **B↔C** 虫洞：进入 A（F1 的 B 侧）会沿 F1 的喉口到 C，
  不是到 B。
- 两个“口”不是同一个虫洞的两端，而是两个 B↔C 虫洞共享 B/C；A→B 必须经过 C。
- `catenoid_test` 的 “A→C→B” 世界线正好证明拓扑错了；它没有检查 A→B。
- 正确的 0.0.2 没有“两个独立口”的同空间 handle：它只有**一张**超悬链面、
  **一个**喉口，喉口两侧就是两个入口/两个宇宙。进入一侧、穿过同一个喉口，
  从另一侧出来；不是两张 B↔C 面，也不是另造一根手柄。
- 光滑 `smin` / 法向连续都修不了拓扑；这是几何对象的拓扑错误，不是数值误差。

## 10. 字面 handle / 体积空间（v46）

**做法**：平房间 + 两个口 + 一条 4D 体积喉管；进入 A 沿喉管到 B。
**打回原因**：
- 用户要的不是“真的做一个手柄一样的空间”；这是另造的体积场景，不是 0.0.2。
- 0.0.2 的连接是**同一张超悬链面的喉口**，不是一根额外的管/体积。
- 即使 A→B 位置连续，几何对象（体积管）与 0.0.2 的超曲面不一致。

**注意**：v47 是 tube 的**边界曲面**，不是体积；它不在本条打回范围内。

# 主 B↔C 的正确方向：严格恢复 0.0.2 单超悬链面

0.0.2 的实现是**一张**超悬链面、**一个**喉口：

```
F(p) = |p_xyz| - R*cosh(w/R) = 0
```

- 一个喉口在 `w=0`，半径 `R`；
- 喉口两侧 = 两个入口/两个宇宙：`B (w>0, 暖)` / `A (w<0, 冷)`；
- 从一侧进入，穿过**同一个喉口**，从另一侧出来；`w` 连续变号；
- 没有第二张曲面、没有 handle、没有位置映射/传送；
- 观察者/光线始终在**同一张**超曲面上，按约束投影测地线积分；
- 视觉是一个中央喉口 + 悬链面地板 + 两侧星空，不是两个并排的玻璃泡；
  两个并排泡属于另一种拓扑（handle/identification），已打回。

实现：直接使用 0.0.2 的 `scenes/main.tscn` + `scripts/main.gd` +
`shaders/wormhole4d.gdshader`；主场景已切回 `main.tscn`。

验收：`tests/throat_test.gd`
- 单曲面 `F=0`；
- 起点 `B (w>0)`、终点 `A (w<0)`；
- 穿过同一个喉口 `w=0`；
- 喉口半径 `R`；
- `w` 连续、3D 位置连续；
- 两侧是同一张超悬链面（`rho(w)=rho(-w)`），没有第二份拷贝。

## 11. 平房间 + tube 边界曲面（v47，打回）

**做法**：`room_f = W0 - w`（平房间面）；`tube_f = |p - C(t)| - R`；
`world = smin(room_f, tube_f)`；玩家在边界曲面上。
**打回原因**：
- 房间是**平的**，不是 0.0.2 的弯曲超悬链面；桥仍然是"平房间 + 外加 tube 边界"的
  **复合结构**，不是同一张弯曲 4D 超曲面自身的几何。
- 虽然玩家在 tube 的边界曲面上（不是体积），但空间的"房间部分"是平的；
  整体不是 0.0.2 的弯曲空间。
- 用户要的是：整个 B 空间本来就是 0.0.2 的弯曲超曲面，handle 是这张曲面自身的一部分，
  不是在平房间上再挂一段桥。

## 12. 0.0.2 B 侧曲面 + 插入的 tube 实体边界（v48，打回）

**做法**：`F_room = -F_0`（0.0.2 实体外部）；`F_tube` 是 B 曲面内侧的 tube 实体；
`world = smin(F_room, F_tube)`；桥面是 tube 边界。
**打回原因**：
- 桥仍然是**插入的 tube 实体边界**，靠 `smin` 拼到 0.0.2 B 面上；这是"B 面 + 管子"的
  **复合结构**，不是同一张超曲面自身的全局几何。
- 虽然房间是弯曲的、桥被 B 面挡住，但几何对象仍是"0.0.2 面 + 外挂/内插 tube"；
  用户要的是**整个空间本身就是一张带颈部/手柄的曲面**。
- 只在 0.0.2 B 面上打补丁，永远会得到"房间 + 连接件"的二分；要把连接变成全局拓扑/几何。

## 13. 独立球/管插入曲面（v48/v49，打回）

**现象**：屏摄里是一个蓝色球/管像异物一样插进灰色曲面，边缘是一圈硬 rim（红箭头）。
**打回原因**：
- 无论 rim 多光滑，嘴仍然是一个**独立的球/管对象**；它是"球/管 + 曲面"的并集，
  不是曲面自身的形状。
- v48 是 0.0.2 B 面 + 内插 tube 实体；v49 是两个 4D 球的平滑并集。
  两者都会得到"球面/叶瓣 + 边界"的观感，而不是一条光滑母线形成的颈。
- 用户要的是：**同一张曲面本身的形状**，母线上有两个叶瓣和一个颈；
  没有球、没有管、没有 rim、没有并集。

# 同空间 A↔B 的正确方向：单一光滑母线旋转出的双叶曲面（v50）

- 世界是一张光滑 3D 超曲面：
  ```
  F(p) = |p_xyz| - f(p.w) = 0
  f(w) = 两个 Gaussian 叶瓣 + 一个颈部
  ```
- 这是一张**绕 w 轴的旋转曲面**：母线上有两个鼓包（叶瓣）和一个细颈；
  两个叶瓣是同一张曲面的两个位置，颈部是它们之间的连接。
- 没有球、没有 tube、没有并集、没有 rim、没有平房间、没有单独的 handle。
- 从叶瓣 A 进入 → 沿同一张曲面通过颈部 → 从叶瓣 B 出来；没有位置映射/传送。
- V 视图直接画母线 \(ρ=f(w)\)，能看到两个叶瓣 + 颈部 + 相机位置。
- 0.0.2 的单喉口 B↔C 是另一张曲面，保留为独立场景。
