# 四维空间 SDF 引擎 + 虫洞（Godot 4）

**分层宇宙 + 井道虫洞**的纯几何实现：三个宇宙是 w 轴上的三张平行层
（A: w=−24 冷蓝 / B: w=0 家 / C: w=+24 暖金），每层是平直 3D 空间
（地板 {z=−2, w=wᵢ} 的精确 2-平面距离场 + 各自色温的星空）。
虫洞全部是 **4D 空间中真实存在的管道几何**（SDF 实体，空心、端口喇叭、
层内平走段 + 弯入 w 的竖井），穿越 = 4D 飞行 + 管壁碰撞（沿壁滑动），
全程连续、无任何传送。平直层内光线不弯——虫洞的可见效果就是管道几何
本身与透过端口看到的另一层。

## 运行 / 构建

- Godot 4.3+ 导入 `project.godot`，F5 运行（本机 4.7.1 已验证）。
- 单文件 exe：`./build.sh "…Godot.exe"`（或 `build.bat`），产物 `build/4DWormholeEngine.exe`。
- 截图验证：`Godot.exe --path . -- --shot=<png> [--shot-pos=x,y,z,w] [--shot-yaw=deg] [--shot-pitch=deg] [--shot-ana-yaw=deg] [--shot-ana-pitch=deg] [--shot-mode=0|1] [--ss=1.5]`

## 数学模型

### 分层宇宙（w 轴上平行）

三张层：`{w = −24}`（宇宙 A，冷蓝）、`{w = 0}`（宇宙 B，家）、`{w = +24}`（宇宙 C，暖金）。
每层内是平直 3D 空间：地板超平面 `{z = −2}` 与层组合为 2-平面
`{z=−2, w=wᵢ}`，其距离场 `√((z+2)² + (w−wᵢ)²)` 精确且天然按层门控。
层是平直的：光线为直线，无伪造的引力透镜。

### 虫洞管道（真 4D 几何）

折线轴 + 喇叭端口 + 空心壁的 SDF 管道（`sd_tube`/`sd_tube2`，端口切平面敞开）：

- **B→C 井道**：`(30,0,0,0) → (30,0,−16,0) → (30,0,−21,17) → (30,0,−1,24)`
  （B 层端口 → 层内平走 16 m → 弯入 +w → C 层端口）；
- **A→B 井道**：`(-30,0,0,-24) → (-30,0,-16,-24) → (-30,0,-21,-7) → (-30,0,-1,0)`；
- **B 层快速通道**：`(-160,0,0,0) → (160,0,0,0)`（320 m 直线，两端端口）。

穿越 = 4D 飞行：飞进端口后管道壁（SDF 碰撞，沿壁滑动）引导路线；
管道在 w 方向弯折处，按住 I/K 把视线转入 w 即可跟随竖井爬升——
这是 4D 飞行的本质，不是脚本化的切片跟随。

### 楼层图 (V)

(x, w) 平面俯瞰：三条平行地板线（三层宇宙）、两条竖直井道连线、
B 层内的横向快速通道、相机标记——分层拓扑一目了然。

## 调参

| 名称 | 默认 | 含义 |
|---|---|---|
| `PORT_R / THROAT_R / TUBE_WALL` | 3.4 / 2.4 / 0.4 | 管道端口半径 / 中段半径 / 壁厚 |
| `W_A / W_B / W_C` | −24 / 0 / +24 | 三张平行层的 w 位置 |
| `MAX_STEPS` | 300 | 步进上限 |
| `SS`（F 键） | 1.5× | 超采样倍率 |

## 文件结构

```
project.godot               工程配置；run/main_scene = exe 入口场景
export_presets.cfg          Windows 导出预设（x86_64、嵌入 PCK）
build.sh / build.bat        一键构建
scenes/main.tscn            SubViewport（超采样）+ 全屏着色器 + HUD
scripts/main.gd             4D 相机、飞行、SDF 碰撞（层约束+管壁）、楼层图、截图自检
shaders/wormhole4d.gdshader  4D SDF（三层地板+三条管道）、材质、楼层图
icon.svg
```

`TUBE_*` 折线在 `main.gd` 与着色器中各有一份常量，修改需同步。
